# Git Diff HTML Report（中文说明）

为 Git 仓库生成 Gerrit/BeyondCompare 风格的并排 HTML diff 报告，附带一个
C/C++ 配色主题。

扩展已完全本地化：当 VS Code 运行在中文（`zh-*`）语言环境下，所有按钮、
提示和消息均显示中文，否则显示英文。

## 功能特性

- **一键生成报告**：状态栏按钮，以及命令面板、资源管理器右键、编辑器右键、
  源代码管理（SCM）视图等多种触发方式
- **提交浏览器**：状态栏按钮会打开一个选择器，列出 `HEAD`、暂存区以及最近的提交
- **单基线对比**：点击某一项，即与工作区当前改动对比
- **双基线对比**：切换到复选框模式，勾选恰好两项，再点「开始比较」
- **分页**：每页 10 条提交，向后翻页（没有更多时按钮变灰）
- **保存 / 另存为**：把最近一次生成的报告保存到默认目录或指定位置
- **指定路径**：右键某个文件或文件夹，只 diff 该路径
- **C/C++ 配色主题**：附带 `Symthosm C/C++` 浅色主题，对关键字、类型、字符串、
  注释、预处理指令、数字进行六色高亮

## 环境要求

- `PATH` 中有 `git`
- `python3`（Linux/macOS）或 `python`（Windows）

## 使用方法

1. 以工作区形式打开一个 Git 仓库
2. 通过以下任一方式触发选择器：
   - **状态栏**：点击左下角的 `Diff Report` 按钮
   - 命令面板（`Ctrl+Shift+P`）→ `GitDiff: Generate Git Diff HTML Report`
   - 在资源管理器、编辑器或源代码管理视图中右键 →
     `Generate Git Diff HTML Report`
3. 选择器会列出 `HEAD`、暂存区以及最近的 10 条提交

### 选择器按钮

| 按钮 | 图标 | 作用 |
| --- | --- | --- |
| 下一组日志 | chevron-down / circle-slash | 加载下 10 条提交；没有更多时变灰 |
| 双基线对比 | checklist | 开启 / 关闭复选框模式 |
| 开始比较 | play | 执行选中的对比 |
| 保存到默认目录 | save | 把最近报告复制到 `<工作区>/git-diff-reports/` |
| 另存为… | save-as | 把最近报告保存到指定路径 |

### 对比模式

- **单选模式（默认）** — 点击某一项（`HEAD`、暂存区或某条提交），即与工作区
  对比，立即执行。
- **双基线模式** — 点「双基线对比」按钮让复选框出现，勾选恰好两项，再点
  「开始比较」。

默认对比「工作区当前改动 vs HEAD」。

## 主题

安装后，进入 `首选项 → 颜色主题`，选择 `Symthosm C/C++`。
